# Simulatore: impresa edile artigiana e azienda agricola

Pagina web statica (un solo `index.html`, nessuna dipendenza da installare) per stimare il reddito netto di un artigiano edile che affianca alla propria ditta un'azienda agricola.

## Cosa calcola

- **Anno tipo:** fatturato e netto della ditta edile in regime forfettario o semplificato, con dipendente operaio, apprendista o assunto con Bonus Giovani; netto dell'azienda agricola; investimenti coperti dal premio di primo insediamento; avvisi su soglie del forfettario, limite di spesa per il personale e prevalenza agricola.
- **Simulatore 2026-2032:** scelte anno per anno (regime, dipendente, inquadramento, avvio dell'agricola, tende glamping) e grafico del netto mensile rispetto all'obiettivo.
- **Due strade per l'agricola:** azienda individuale con vivaio, funghi e glamping in agricampeggio, oppure società agricola con frantoio.

## Note

- I valori iniziali sono di esempio. I dati inseriti restano nel `localStorage` del browser e non vengono inviati altrove.
- Le aliquote e le soglie sono indicative e aggiornate a novembre 2026. Lo strumento non sostituisce commercialista, consulente del lavoro o tecnico agricolo.
- Pubblicazione: GitHub Pages dalla radice del branch principale.
